### 1. 📘 [دليل مشروع ZaWolf المعماري والتشغيلي النهائي](./دليل_مشروع_ZaWolf_المعماري_والتشغيلي_النهائي.md)
* **الوصف:** الدليل المرجعي الأساسي لتشغيل وفهم المنظومة.
* **المحتويات:** المعمارية الهندسية، مخططات Mermaid التفاعلية، الركائز الست المتطورة، تشريح طبقات الكود الـ 42، بنية الجداول الـ 19، نتائج التقييم الميداني (100% نجاح)، ودليل تشغيل بايثون والـ API.

### 2. 🏛️ [الموسوعة الهندسية الشاملة لمعمارية وأكواد ZaWolf](./الموسوعة_الهندسية_الشاملة_لمعمارية_وأكواد_ZaWolf.md)
* **الوصف:** الكتاب المرجعي الموسوعي الشامل المقسم إلى 12 باباً فصلياً.
* **المحتويات:** دستور المنظومة وقواعدها الـ 22 الصارمة، تشريح الكلاسات والدوال، تفاصيل محركات الـ OCR الهجينة، آليات حارس الاستخراج لمنع الهلوسة، الفهارس التغطوية الـ 13، وتفاصيل التراجع الذري لقاعدة البيانات.

### 3. 📦 [حزمة الأكواد الكاملة والمواصفات المعمارية لمشروع ZaWolf](./حزمة_الأكواد_الكاملة_والمواصفات_المعمارية_لمشروع_ZaWolf.md)
* **الوصف:** حزمة التصدير البرمجية الشاملة (All-In-One Codebase Bundle).
* **المحتويات:** الكود المصدري الحرفي والكامل سطر بسطر لكافة ملفات المشروع (38 ملفاً برمجياً تشمل الـ API والـ Pipeline ومعالجات الـ OCR وقاعدة البيانات وسكربت التقييم) مما يجعل أي مطور أو نموذج ذكاء اصطناعي مكتفياً ذاتياً بالكامل.

### 4. 🧠 [سياق المشروع المحسن لنماذج الذكاء الاصطناعي ZaWolf](./سياق_المشروع_المحسن_لنماذج_الذكاء_الاصطناعي_ZaWolf.md)
* **الوصف:** ملف السياق فائق الكثافة المهيأ لنافذة السياق (Working Memory / System Prompt) لنماذج الـ LLM.
* **المحتويات:** القواعد الهندسية الثابتة، مواصفات الـ APIs، مخططات الـ JSON الإلزامية، مواصفات الحقول والمفاتيح الأجنبية لقاعدة البيانات `ZaWolfDB`.
